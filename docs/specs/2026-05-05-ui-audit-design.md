# imageMaker UI 诊断审计 — 设计规格

## 目标
对 imageMaker 桌面应用的全部前端 UI 进行一次静态代码审计，识别拥挤、低对比度、不美观及可用性问题，输出结构化诊断报告。

## 审计方法论
采用**纯代码静态启发式审计**：
- 遍历 `src/widgets/` 下所有面板与组件源码
- 读取 `src/widgets/theme.py` 的完整配色与尺寸系统
- 计算关键前景/背景色组合的 WCAG 2.1 对比度比值
- 检查布局参数（spacing、margins、min/max size、widget 密度）
- 识别跨面板重复的设计不一致

不运行应用，不依赖截图。

## 审计范围

| 层级 | 文件 | 关注点 |
|------|------|--------|
| 设计系统 | `theme.py` | 配色对比度、字体层级、圆角/间距一致性 |
| 主框架 | `main_window.py` | 三栏比例、最小尺寸、全局边距、渐变背景 |
| 生成面板 | `generation_panel.py` | 控件密度、输入区高度、按钮排列、状态提示 |
| 历史面板 | `history_panel.py` | 缩略图网格间距、诊断区折叠、操作按钮密度 |
| 提示词面板 | `prompt_panel.py` | 分类栏高度、卡片间距、添加按钮位置 |
| 设置对话框 | `settings_dialog.py` | 表单项密度、标签对齐、Tab 分布 |
| 图片查看器 | `image_viewer.py` | 控件布局、信息密度 |
| 可复用组件 | `src/widgets/components/*.py` | 卡片内边距、文字截断、按钮尺寸 |

## 报告结构

1. **设计系统总览**
   - 配色体系评价
   - 字体层级评价
   - 全局间距/圆角规范一致性

2. **分面板诊断**（逐项列出）
   - 问题描述
   - 代码位置（文件:行号）
   - 严重程度：Critical / Warning / Suggestion

3. **跨面板系统性问题**
   - 对比度不足的色值组合（附 WCAG 比值）
   - 反复出现的拥挤模式
   - 对齐/间距不一致

4. **问题汇总表**
   - 按严重程度排序的速查清单

## 成功标准
- 覆盖范围 ≥ 全部 8 个审计对象
- 每个 Critical/Warning 附带代码位置
- 对比度数值基于 WCAG 2.1 AA 标准（4.5:1 正文，3:1 大号文字/UI 组件）
- 报告独立可读，无需运行应用即可理解

## 排除项
- 不涉及后端逻辑、API 适配器、数据库性能
- 不修改任何代码（纯诊断）
- 不评估功能完整性（仅评估 UI 呈现）
